# CS-210-Portfolio
My CS 210 Programming Languages portfolio at Southern New Hampshire University.

## Corner Grocer Project Three Reflection

### 1. Summarize the project and what problem it was solving.

For this project, I created a C++ program for a grocery store called Corner Grocer. The purpose of this program was to help the store keep track of what items customers purchased the most. The program allows users to search for an item, see how many times it was purchased, and look at a list of items using a histogram. Overall, this program helps the store keep track of what customers are buying.

### 2. What did you do particularly well?

I think I did a good job making sure the program worked the way it was supposed to. I was able to create a menu that allowed users to choose different options and get the information they needed. I also made sure the program could count the items correctly and display the results. I was happy to see everything working after testing it.

### 3. Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

I think I could improve my code by making it a little more organized and easier to understand. I could also add more ways for the program to handle mistakes, like when someone enters the wrong option. This would help prevent errors and make the program easier to use.

### 4. Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

The most challenging part for me was getting everything in the program to work together. I had to make sure the menu options worked correctly and the program displayed the right information. I was able to work through this by testing my code, reviewing the instructions, and using resources to help me understand what I was doing. I plan to keep using my course materials and other coding resources whenever I need help.

### 5. What skills from this project will be particularly transferable to other projects or course work?

One skill I learned from this project was how to use C++ to create a program that solves a problem. I also got more practice working with loops, functions, and files. These are skills that I can use again in future programming classes. I also learned how important it is to test my code to make sure everything works correctly.

### 6. How did you make this program maintainable, readable, and adaptable?

I tried to keep my code organized so it would be easier to read and understand. I used functions to separate different parts of the program instead of putting everything together. This also makes it easier to go back and make changes without having to rewrite the entire program. If I wanted to add more features later, I would have a better idea of where to start.
